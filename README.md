# Scrdows – A Scratch-based Windows Simulation

**Scrdows** is a creative project that mimics the look and feel of a modern operating system, built entirely with **Scratch** (and optionally enhanced with TurboWarp). It simulates a Windows-like desktop environment, complete with a file explorer, recycle bin, settings panel, and even an Insider update system – all inside your browser.

## ✨ Features

- 🖥️ **Desktop Interface**: A realistic desktop with folder browsing (C:\Program Files, C:\Scrdows, C:\ScrRe)
- 📂 **File Explorer**: Browse virtual folders and “files” with icons and metadata
- ⚙️ **Settings Panel**: Tweak system behaviors (e.g., theme, animations)
- 🔄 **Insider Program**: Channel-based updates (Canary / Dev / Beta)
- 🧪 **Boot Animations & BSOD**: Easter eggs and fake crash screens for fun
- 💾 **Fully client-side**: Runs in Scratch or TurboWarp – no installation needed

## 🚀 Getting Started

### Play online (no download)
1. Go to [https://scrdows.github.io](https://scrdows.github.io)
2. Click the green flag and wait for the desktop to load
3. Explore folders, double‑click icons, and enjoy the parody!

### Run locally (with Scratch or TurboWarp)
- Download the latest `.sb3` file from the [Releases](https://github.com/scrdows/scrdows.github.io/releases) section
- Open with Scratch 3.0 or TurboWarp (recommended for better performance)

## 🛠️ Build & Contribute

Scrdows is open for ideas and collaboration. Since it’s built visually in Scratch, contributing is different from traditional code:

- **Report issues**: Open a GitHub Issue with a clear description and screenshot.
- **Suggest features**: Use the Discussions tab.
- **Remix your own version**: Fork the repository and modify the `.sb3` file using TurboWarp or Scratch.

> If you know how to reverse‑engineer Scratch projects, you can help optimize the vector graphics or reduce sprite count.

## 📁 Repository Structure

- `Scrdows.sb3` – The main Scratch project file
- `assets/` – Icons, fonts, and other static resources
